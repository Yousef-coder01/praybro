PrayBro

A Discord bot that provides prayer times and prayer notifications based on user and server locations.

Features
Set personal and server locations
Check the next prayer
View prayer times
Enable or disable server notifications
PostgreSQL database for persistent settings
Supports multiple Discord servers
Built With
Node.js
/Discord.js
/PostgreSQL
/Railway
/Commands
/setlocation
/nextprayer
/prayertimes
/setserverlocation
/setnotification
Setup

Create a .env file with your Discord and PostgreSQL credentials, then:

npm install
npm start
Deployment

The bot is deployed on Railway with PostgreSQL for persistent data.

Built as a backend learning project.
